# 版本变更记录

## v1.2.2 (2026-10-14)

### 窗口行为
- “最小化”不再只是藏进托盘：窗口以类似 macOS 的缩放动画（约 0.3 秒）收进桌面右侧边的一个小标签，继续在后台记录
- 单击小标签、单击托盘图标或按 Alt+V，窗口从标签位置缩放展开回原位置；展开前会先刷新列表，动画结束时与真实窗口无缝衔接
- 小标签贴着屏幕右缘，悬停时微微探出；可上下拖动换位置，位置会记住（`dock_y`），默认跟随窗口中线；点标签不抢前台焦点，展开后仍能粘贴回之前的窗口
- 收起动画途中被 Alt+V / 托盘呼出会立即还原
- 去掉“点到别处退到被点击窗口后面”的降图层行为：未开启“保持显示”时，点到别处（窗口失去激活）自动最小化到右侧边小标签；保持显示、模态对话框 / 右键菜单打开、前台仍是本程序窗口时不触发
- Esc、Alt+V 隐藏、托盘单击隐藏、选择粘贴后的隐藏，统一改为同样的缩放收进小标签
- 点托盘瞬间窗口会先因失去激活而自动收起，托盘随后的单击不再把它弹出来
- 优化收起时“闪一下再缩小”：先把截图层画出来再藏真实窗口（原来中间会空一帧），并提前创建动画窗口、展开收尾时多留一小会儿截图

### 验证
- 27 项回归：收起停靠 / 点击展开 / 重复呼出不重入、动画途中打断、标签拖动记忆位置，以及失去激活自动收起的各种例外（固定、模态框、本程序窗口、从未激活）、Esc / 托盘 / Alt+V；真机核对点桌面后自动收起、点标签展开并重新激活

## v1.2.1 (2026-10-12)

### 窗口行为
- 未开启“保持显示”时，点到别处不再直接隐藏，而是退到被点击窗口的下一层，仍留在桌面上，不挡住正在使用的窗口
- 点任务栏、桌面或置顶窗口时，只取消置顶、留在普通窗口最上层，等切到下一个窗口后自然被盖住
- 被压在后面时，Alt+V 或再次启动程序会把窗口带回最前；窗口在前台时 Alt+V 仍是隐藏
- 点回窗口露出的部分会重新置顶；打开设置/预览等对话框时位置不变
- 单击托盘图标即可显示/隐藏（原为双击）：窗口看得见就隐藏，被别的窗口盖住或已隐藏就带到最前；托盘菜单“显示/隐藏”同此规则
- 标题栏右上角新增“最小化”按钮，作用是收起到托盘并继续记录，可用 Alt+V 或单击托盘图标呼出
- 右上角“✕”改为退出程序，点击后先提示“退出后将不再记录复制的内容”，默认选中“取消”；只想收起窗口请用“最小化”或 Esc / Alt+V
- 选择粘贴后窗口仍会隐藏（保持显示时除外），行为不变

### 验证
- 新增 8 项回归（共 24 项）；另用真实窗口核对：退到后面后正好位于被点击窗口的下一层、再次呼出恢复置顶，以及“是否被盖住”的判断

## v1.2.0 (2026-10-10)

### 内容与操作
- 图片原图无损保存，列表缩略图独立存储；旧历史图片标明缩略图限制
- 完整文字/图片预览，复制与粘贴分别操作，点击默认行为可设置
- 自动粘贴校验窗口句柄、进程、前台焦点及剪贴板版本，失败提示手动粘贴
- 保留期限移到设置，缩短时显示删除数量并确认；时间筛选不删除数据

### 效率与管理
- 键盘选择/粘贴/复制/预览，类型、收藏和时间筛选，搜索词高亮
- 每页60条、继续加载全部历史，展示总数/匹配数/已加载数
- 同内容去重更新最近时间，自身回贴不新增历史；增量更新并保持滚动位置
- 收藏与窗口保持显示分别命名；单条删除10秒内可撤销

### 隐私与交付
- 暂停/恢复记录及托盘入口，运行应用选择与完整进程名排除
- 清空历史确认，可选择包含收藏；容量限制、定时过期清理与数据库空间回收
- 设置原子保存、错误提示和本地日志；可改全局快捷键及冲突反馈
- 开机自启选项、使用说明与独立Windows单文件程序
- 合成数据16项回归通过，默认/最小空状态/文本及图片预览/设置页渲染检查

## v1.1.1 (2026-10-10)

### 窗口行为
- 固定窗口继续置顶且不自动隐藏，允许通过标题栏拖动移动，移动后记住新位置
- 标题栏在固定状态下也显示移动光标，图钉提示同步说明可拖动

## v1.1.0 (2026-10-09)

### 界面
- 整体改为 Apple 风格：浅灰窗体 + 白色卡片、单一强调蓝、圆角无边框窗口加柔和阴影
- emoji 按钮换成系统 Segoe Fluent Icons 线性图标
- 保留期限下拉框改为分段控件；“清理过期”改为文字链接
- 卡片：两行省略号预览、来源应用显示、图片缩略图圆角裁切、操作按钮悬停才出现
- 新增空状态提示；设置对话框、托盘菜单、Tooltip 同步换肤

### 窗口行为
- 标题栏可拖动窗口；四边四角可拖拽缩放（最小 320×380）
- 记住窗口位置和大小，下次呼出保持原位
- 新增“固定在桌面”：不自动隐藏、位置锁定，点卡片粘贴后窗口留在原处
- 未固定时点到别处自动隐藏（原 focusOutEvent 挂在顶层窗口上，实际不会触发）

### 修复
- 列表第一条（最新或置顶）被排到最底部：重建列表时先删了弹簧再插卡片，首张卡片插入下标为 -1

## v1.0.0 (2026-05-09)

### 新增
- 剪贴板实时监控（文字 + 图片）
- 卡片式历史展示（时间降序，置顶优先）
- 搜索过滤功能
- 置顶/删除操作
- 点击粘贴到活动窗口
- 系统托盘 + 右键菜单
- 全局快捷键 Alt+V
- 保留期限设置（1/3/5天）
- 隐私排除应用列表
- 过期自动清理
- 淡蓝色简洁主题

### 技术变更
- 最终采用 Python + PySide6（初始计划 Electron 因模块解析问题放弃）
