# UI 设计规范

> v1.2.0 当前交互：顶部为全部/文字/图片/收藏与时间范围筛选（只筛选，不删除）、暂停记录；底部为预览/复制/粘贴与反馈。点击默认完整预览，可在设置中改为只复制或直接粘贴。保留期限仅在设置中修改，缩短时确认删除数量。收藏不自动过期，窗口图钉名称为“保持显示”。每页60条并支持继续加载；以下v1.1布局示意为历史版本。

> v1.1.0 起改为 Apple 风格：大量留白、克制的中性灰、单一强调蓝、细线条图标。
> 色值统一在 `main.py` 的 `COLORS` 字典里，样式表只引用字典，不写死色值。

## 1. 色彩系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 强调色 | `#0066CC` | 链接、聚焦环、激活态（悬停 `#0077ED`） |
| 窗体背景 | `#F5F5F7` | Apple 浅灰 |
| 卡片背景 | `#FFFFFF` | 白色卡片 + 1px `rgba(0,0,0,0.08)` 细边 |
| 系统填充色 | `rgba(118,118,128,0.12)` | 搜索框、分段控件底色 |
| 文字主色 | `#1D1D1F` | 标题、正文 |
| 文字二级 | `#6E6E73` | 图标按钮 |
| 文字三级 | `#86868B` | 时间戳、计数、空状态 |
| 置顶标记 | `#E85D04` | 橙色实心图钉 |
| 删除 | `#E30000` | 仅悬停时出现 |

## 2. 窗口规格
- 默认窗体 400 × 560 px，最小 320 × 380 px，四边四角均可拖拽缩放
- 无边框圆角窗体（14px）+ 外圈 10px 柔和阴影，阴影区同时是缩放热区
- 首次在鼠标所在屏幕右上角弹出；之后记住上次的位置和大小（`settings.json` 的 `window_geometry`）
- 按住标题栏拖动窗口
- **固定在桌面**（标题栏图钉按钮，类似微信置顶）：
  - 未保持显示：点到别处自动隐藏；选择粘贴时校验并切回目标后隐藏
  - 保持显示：保持置顶、不自动隐藏，可拖动标题栏移动（仍可缩放）；选择粘贴时校验目标，窗口保持可见
  - 状态持久化到 `window_pinned`

## 3. 布局结构

```
┌──────────────────────────────┐
│ 剪贴板              📌 ⚙ ✕  │  ← 标题栏（拖动手柄）
│ 🔍 搜索                      │  ← 系统填充色搜索框
│ [1天|3天|5天] 清理过期   6 条 │  ← 分段控件 + 文字链接 + 计数
│ ┌──────────────────────────┐ │
│ │ 文字预览，最多两行…   📌 │ │  ← 置顶卡片：橙色图钉常显
│ │ 2天前 · WeChat           │ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ [缩略图] 图片     📌 🗑  │ │  ← 悬停时出现操作按钮
│ │          30分钟前 · ...  │ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

## 4. 卡片设计
- 卡片高 76px，圆角 12px，间距 8px
- 文字卡片：连续空白压成一个空格，最多两行，放不下时末行加省略号；随窗口宽度重排
- 图片卡片：左侧 44×44 圆角缩略图（居中裁成正方形），右侧 "图片" + 时间
- 第二行元信息：相对时间 · 来源应用
- 悬停：边框变为强调蓝半透明；置顶/删除按钮仅悬停时出现
- 列表为空时显示空状态文案（区分“无记录”和“搜索无结果”）

## 5. 图标
- 使用系统自带 Segoe Fluent Icons（Win10 回退 Segoe MDL2 Assets），不再使用 emoji
- 码位见 `main.py` 的 `ICONS` 字典

## 6. 字体
- 字体栈：`PingFang SC` → `Segoe UI` → `Microsoft YaHei UI`（拉丁字走 Segoe UI，中文走雅黑）
- 标题：16px / 700
- 卡片正文：13px；时间戳：11px，三级灰
- 搜索框：13px
