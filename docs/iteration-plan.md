# 历史剪贴板迭代计划

日期：2026-10-10

目标：快速找回复制过的内容，并准确、可控地粘贴到目标位置。保留窗口常驻置顶且可拖动的行为。

## 执行顺序与验收

### 第一阶段：内容完整与操作可信赖
- [x] 新复制的图片保存原图，列表只加载缩略图；显示尺寸和大小，管理存储容量。旧缩略图标明历史限制。
- [x] 提供完整文本/图片预览、明确的复制和粘贴动作及默认动作设置。
- [x] 粘贴前与发送按键前校验目标窗口，失败时退回只复制并提示；不声称无法验证的粘贴成功。
- [x] 保留期限移到设置；缩短期限显示删除数量并确认；主界面筛选只筛选、不删除。
- 验收：原图像素保真；无目标/目标失效不发送按键；取消修改不删除数据。

### 第二阶段：检索与连续使用效率
- [x] 上下键选择、Enter 粘贴、Ctrl+Shift+C 只复制、Space 预览、明确选中状态。
- [x] 全部/文字/图片/收藏筛选、独立时间范围、搜索词高亮。
- [x] 内容去重，重复复制更新最近时间，工具自身回贴不产生新历史。
- [x] 增量更新并保持浏览位置；分页加载、显示总数与匹配数。
- [x] 收藏不自动过期；删除提供短时撤销；常驻按钮改为“保持显示”。
- 验收：超过500条可全部访问；筛选不改变数据库；新记录不导致用户浏览位置跳变。

### 第三阶段：隐私与长期运行
- [x] 暂停/恢复记录、明显状态、托盘入口；从运行应用中选择排除项。
- [x] 清空历史入口，明确是否包含收藏；单条删除可撤销。
- [x] 定时清理过期记录、容量限制、设置原子保存、数据库迁移和异常反馈。
- [x] 可修改呼出快捷键及冲突提示；首次使用指引。
- 验收：暂停/排除时不记录；过期清理保护收藏；重启保留设置与历史。

### 第四阶段：安装交付与回归
- [x] 独立Windows可执行文件，桌面快捷方式不依赖固定Python路径。
- [x] 开机自启设置、版本信息、使用说明与更新方式。
- [x] 对数据、剪贴板、目标校验、筛选分页与交互运行针对性回归；离屏渲染检查布局。
- [x] 重启桌面工具并确认运行；记录人工兼容性测试范围与限制。
- 验收：已有历史完整保留、启动正常、语法和回归检查通过，产物可直接运行。

## 实施原则
- 修改前备份源码、设置与数据库；保留既有未提交修改。
- 不读取或导出用户剪贴板正文作为测试数据，测试使用临时数据库和合成内容。
- 原图保存从此次升级后生效，旧图无法恢复缺失像素。
- 自动粘贴只在目标窗口校验通过时尝试；跨应用接收结果仍需真机验证。
- 暂不增加云同步、OCR、AI改写等功能，先完成基础体验。
