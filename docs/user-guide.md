# 历史剪贴板 v1.2.2

双击 ClipboardHistory.exe 即可运行，无需安装 Python。请放在有写入权限的文件夹中，例如桌面工具文件夹。

## 常用操作
- Alt+V：展开或收起。可在设置中修改；被占用时会显示提示。
- 点击记录：默认完整预览。设置中可改为只复制或直接粘贴。
- 上下键：选择记录；Enter：粘贴；Ctrl+Shift+C：只复制；Space：预览（搜索输入时空格正常输入）；Esc：收起到右侧边小标签。
- 右键记录：预览、复制、粘贴、收藏和删除。
- 顶部图钉：保持显示，始终置顶，仍能拖动标题栏移动。未开启时，点到别处窗口会自动缩进桌面右侧边的小标签；开启后点到别处也不会收起。
- 托盘图标：单击收起/展开（收起时同样缩进右侧边小标签）；右键有菜单。
- 顶部“最小化”：窗口缩成桌面右侧边的一个小标签，继续记录；单击小标签、单击托盘图标或按 Alt+V，窗口会从标签位置缩放展开。小标签可上下拖动换位置。Esc、Alt+V、托盘单击、粘贴后隐藏、点到别处，都是同样的收起方式。
- 顶部“✕”：退出程序。退出后不再记录复制的内容，点击时会先提示确认。只想收起窗口请用“最小化”。
- 收藏：置顶显示且不自动过期。收藏独立于窗口的保持显示。
- 全部/文字/图片/收藏及时间范围：仅筛选，不删除内容。
- 删除记录：10秒内可以撤销最近一次删除。
- 暂停记录：暂停后新复制内容不会保存；也可通过托盘菜单操作。

## 设置
- 保留期限仅影响未收藏记录。缩短期限会显示将删除的数量并要求确认。
- 达到容量/条数上限时清理最旧未收藏记录；收藏占满时暂停新记录并提示。
- 排除应用可从正在运行的应用中选择，也可输入完整进程名。排除浏览器会影响整个浏览器。
- 可以启用开机自启。该选项默认关闭，不会自动替用户启用。
- 清空历史会要求确认，可以选择是否包含收藏；清空无法撤销。

## 图片与粘贴
- 升级后保存图片原图，列表使用缩略图；预览支持适应窗口、100%和200%。
- 老版本只保存200px缩略图，历史图片会标明限制，缺失像素无法恢复。
- 粘贴前校验目标窗口；目标失效、焦点或剪贴板变化时取消自动粘贴。
- “已发送粘贴操作”表示已发送按键，无法保证所有目标应用接收；如未接收，请手动Ctrl+V。
- 不同权限等级、远程桌面和应用自身限制仍可能影响自动粘贴。

## 数据与更新
- 历史在程序同目录的 data 文件夹中，仅本地保存，未加密。不上传历史内容。
- 分享程序时只分享 exe 和本说明，不要带上个人 data 文件夹。
- 更新时退出工具、备份 data 文件夹，然后替换 exe，保留 data 文件夹即可。
- 如果开启自启后移动程序，请在新位置重新保存自启设置。
- 意外操作错误会显示提示，详情保存在 data/errors.log；该日志不主动记录历史正文。

本次提供免安装的单文件Windows程序。未加入联网自动更新、OCR、云同步或AI改写。
